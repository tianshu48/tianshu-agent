# tianshu-agent

Public release assets for the agent that ships with [Tianshu](https://github.com/tianshu48/tianshu). This repository holds Release attachments only: one `tianshu-agent` binary per platform, and a `SHA256SUMS` file for each tag.

The agent is a modified build of [openai/codex](https://github.com/openai/codex) (Apache-2.0). The Tianshu installers bundle it, so you do not need to download anything here to use the desktop app.
